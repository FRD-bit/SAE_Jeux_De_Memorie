comme il n'y avais pas d'idée pour des amélioration du jeux, il a été décider de rajouter un système de customisqtion bassiquement, il y a 5 choses qui peuvent être customisé:

- la musique, il suffit de mêtre le fichier audio désirer dans le dossier "sound" et de remplacer "val_loop.mp3" dans le HTML par le nom du fichier
- le font d'écrant, il suffit supprimer l'image "back.png" et de rajouter le nouveau font d'écrant en lui donnant le nom "back.png" (remplacer le png par le - type de fichier image)
- les cartes, il suffit de rajouter les image désirer dans le fichier "custom" et d'aller dans "ImageCollection.js" et de remplacer le nom de l'image dans le - lien existant par le nom de la nouvelle image
- le dos des cartes, faire parreille que pour le font d'écrant mais en renoment l'image "ba.le_type_de_fichier"


On a également ajouté un tableau de score local, qui permet de trier nos score 
De plus un mode flash existe, ce dernier si sélectionner permet au joueur de voir toutes les cartes pendant 3 secondes avant qu'elles ne se retournent.
ajout d'un bouton mute/Unmute dans le jeu pour permettre de desactiver ou d'activer la musique
